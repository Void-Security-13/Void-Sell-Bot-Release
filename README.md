# Void Bot

ربات فروشگاهی تلگرام برای فروش سرویس با اتصال به پنل‌های مدیریت VPN.

## نصب

روی سرور خودتون (Ubuntu/Debian با دسترسی sudo):

```bash
curl -O https://raw.githubusercontent.com/Void-Security-13/Void-Bot-Release/main/get-void-bot.sh
bash get-void-bot.sh
```

موقع اجرا ازتون یه **Access Token** می‌خواد که از فروشنده (همراه کد لایسنس)
دریافت می‌کنید. بعد از وارد کردن توکن، نصب به‌صورت کامل خودکار انجام می‌شه:
توکن ربات، آیدی ادمین، تنظیمات فروشگاه و کد لایسنس رو ازتون می‌پرسه و در
نهایت ربات به‌عنوان سرویس سیستمی نصب و اجرا می‌شه.

## مدیریت بعد از نصب

```bash
cd ~/void-bot
bash void-bot.sh
```

## پشتیبانی

برای دریافت Access Token و کد لایسنس، یا سوالات نصب، با فروشنده تماس بگیرید.
